About This Project

What this app does

This weather application helps users view real-time weather data in a simple and easy to understand format. It pulls weather information from a backend API and displays it in a user-friendly dashboard.

Who it is for

This application is designed for students, commuters, travelers, and anyone who needs quick and clear weather updates.

Data Source

The backend connects to the Open-Meteo Weather API and also stores location data using Supabase.

Why it matters

Weather information is often complex. This project simplifies it by processing data through a backend server before displaying it.
