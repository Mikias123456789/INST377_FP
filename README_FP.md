# Title of Project: Weather Application

# Name: Mikias Zenebe

# Description of Project

This is a weather web application built using Node.js, Express, and frontend JavaScript. The application allows users to search for cities and view current weather conditions, hourly forecasts, and temperature trends. It also includes an interactive map using Leaflet.js and a chart visualization using Chart.js.

Users can do the following:
- Search for a city to view weather data
- View current weather conditions (temperature, wind, and forecast conditions)
- View hourly temperature forecasts for the next 6 hours
- View weather trends using a chart
- View locations on an interactive map
- Save cities and reload previously searched locations

The frontend communicates with a backend server that connects to external weather APIs and a Supabase database.

# Description of Target Browsers

This application is designed for web browsers including:
- Google Chrome (most recommended)
- Firefox
- Microsoft Edge
- Safari (iOS and macOS)
- Mobile browsers on Android and iOS devices
